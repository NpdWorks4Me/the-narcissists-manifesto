# 🛠️ Vault Setup Guide

## Quick Start

> **All code lives in `05 Backend/`** — run commands from there. Vault root is pure Markdown.

```bash
cd "05 Backend"
npm install --cache /tmp/npm-cache
npm run vault:setup-plugins   # installs Dataview, Templater, Tasks, Tracker, Linter, Obsidian Git
npm run vault:check           # validates frontmatter + links + WIP
npm run vault:daemon -- --once --dry-run  # preview engines without mutating
```

Then open Obsidian → **Settings → Community plugins → Enable** (should already be enabled) → check **Dataview, Templater, Tasks, Tracker, Calendar, Linter**.

## Folder Map

- `00 Inbox` → raw captures
- `01 Hyperfixations` → active/parked research rabbit holes (`type: hyperfixation`)
- `02 Atomic Concepts` → evergreen reusable notes (`type: atomic-concept`)
- `03 Content Lab` → pipeline (`type: content-project`)
- `04 Atlas & Meta` → system, templates, dashboards, logs

## Templates

Use `Ctrl/Cmd+P → Templater: Insert template` → pick `T_Hyperfixation`, `T_Atomic_Concept`, or `T_Content_Spec`. Templates live in `04 Atlas & Meta/Templates/`.

## Dashboards

- `04 Atlas & Meta/Dashboards/🏠 Command Center.md` — WIP, inbox triage, content candidates, stale projects, Tasks queue, Tracker velocity.
- `04 Atlas & Meta/Dashboards/📈 Knowledge Graph Intelligence.md` — weekly report generated by Engine B (`npm run vault:report`).

## Automation

- **Instant:** `00 Inbox` watcher handles new files within ~2s when daemon runs (`npm run vault:daemon` from `05 Backend/`).
- **Daily 09:00:** hygiene (WIP, orphans, broken links, semantic).
- **Weekly Sunday 18:00:** knowledge graph report.
- macOS `launchd` plist is at `05 Backend/src/vault/com.narcissist-manifesto.vault.plist` — copy to `~/Library/LaunchAgents/` and `launchctl load` to persist (requires approval). Legacy path `04 Atlas & Meta/Scripts/` now contains a README shim.

## Manual Plugin Install (if automated fetch fails)

1. Obsidian → Settings → Community plugins → Browse → search each plugin name → Install → Enable.
2. Required: Dataview, Templater. Recommended: Tasks, Tracker, Calendar, Linter. Optional: Obsidian Git.

## Tracking

Events append to `04 Atlas & Meta/Logs/tracking.csv` (read by Tracker). View charts in Command Center's Tracker block. Git (if enabled) auto-commits changes for undo.

## Troubleshooting

- `vault:check` reports missing plugins → re-run `vault:setup-plugins` or install manually.
- Dataview shows "No results" on empty vault → expected; add notes to see data.
- Daemon not reacting → ensure `npm run vault:daemon` is running or `launchd` loaded.
