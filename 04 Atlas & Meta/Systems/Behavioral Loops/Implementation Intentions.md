# Implementation Intentions

## For future agent

> **Summary:** Atomic on Gollwitzer's Implementation Intentions `If [situation] → Then [action]` — pre-commits routine to a cue to bypass executive function. Status `synthesized` as of `2026-09-02`. Use in `resume_point.next_step` and kanban cards as the delegation syntax to future-self.
> **Load:** Read `SOUL.md` + `CRITICAL_FACTS.md`.

## Definition

**Implementation Intention (Gollwitzer, 1999, timeless)** — A pre-decided `If [situation/cue] → Then [I will do SPECIFIC action]` plan that automates initiation. The decision is made *now*, execution is triggered *later* by the cue without deliberation. Doubles follow-through vs vague intention.

## Nuance

- Vague: `"Work on dopamine-loops"` → fails. If-Then: `"If I open dopamine-loops.md after 10am, then I will write 1 sentence under ## Synthesis"` → succeeds.
- Must be ultra-specific: situation includes *when + where + cue* (file, banner, time). Action includes *verb + file + definition of done + timebox*.
- For ADHD, intentions must be *externalized* in vault: write them as Tasks `- [ ] If... Then... 📅 today` so vault (not working memory) holds them.
- Combines with Habit Loop: If-Then *is* the Cue→Routine wiring. Vaultd's 09:00 ping is the perfect `If` trigger.

## Examples

- Kanban card: `- [ ] If I move [[hook-model]] to Doing, then I will draft Hook checklist for 15m 📅 2026-09-03 #delegated`
- Anti-example: `- [ ] Work on hook model` (no If, no Then, no file, no done)

## ADHD Self-Delegation Syntax

Delegate to self like to an employee: `If [I see X / at TIME in Y], Then I will [VERB] [FILE/SECTION] for [TIMEBOX] until [DONE]`. Add `📅` date so Tasks sorts by urgency. The `If` is the permission slip future-you needs.
