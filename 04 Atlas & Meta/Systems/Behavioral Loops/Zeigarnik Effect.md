# Zeigarnik Effect

## For future agent

> **Summary:** Atomic on Zeigarnik Effect — unfinished tasks intrude until closed. Status `synthesized` as of `2026-09-02`. Weaponize via `resume_point.current_thought` left *intentionally unfinished* + kanban `Doing` column.
> **Load:** Read `SOUL.md`.

## Definition

**Zeigarnik Effect (Zeigarnik, 1927, timeless)** — `Unfinished task → intrusive recall → cognitive nag until closed.` Brain keeps open loops active, finished tasks fade. ADHD brains amplify this — open loops can be torture *or* fuel.

## Nuance

- Vault already weaponizes this: `resume_point: {current_thought: "dopamine anticipation — need to map...", next_step: "Map variable reward..."}` The `current_thought` is an *open loop sentence fragment* — your brain will intrude to close it.
- Kanban `Doing` column with 1-3 cards *is* a Zeigarnik engine: visible open loops nag you to drag to Done. Inbox with 0 items = no nag = don't clear it prematurely — leave 1 intentional open loop.
- Danger: too many open loops (WIP 14/5 you had on 2026-09-01) = intrusive overwhelm → shutdown. WIP 5 is the Zeigarnik throttle.
- Closing ritual matters: drag to Done + update `resume_point` + `tracking.csv` — brain gets closure signal.

- Delegation: Leave `resume_point.current_thought: "Hook checklist — trigger design half-done, need reward variability..."` — future-you *has* to return

## ADHD Self-Delegation

Delegate by *leaving* an open loop: end any work session by writing `- [ ] If I open my content note tomorrow, then finish reward checklist (left at tribe/hunt) 📅 tomorrow` and leaving `current_thought` unfinished. You delegate the nag.
