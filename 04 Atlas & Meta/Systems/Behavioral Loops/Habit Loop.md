## Definition

**Habit Loop (Duhigg, 2012, timeless)** — `Cue → Routine → Reward`. The minimal dopamine loop: a trigger cues a behavior, the behavior runs, a reward closes the loop and strengthens the cue-association. Unlike Hook, no Investment phase — lower friction, better for starting.

## Nuance

- Hook has 4 steps + Investment (stores value). Habit Loop has 3 — use Habit Loop when you can't get started, Hook when you want to *compound* a habit.
- Cue must be unmissable for ADHD: visual (Command Center WIP banner), temporal (09:00 vaultd ping), or contextual (opening `01 Hyperfixations/dopamine-loops.md`).
- Reward must be immediate and variable-ish: Tracker velocity +1, Engine B insight, or dice-roll (Hunt/Self/Tribe). Fixed rewards bore — same failure as fixed paychecks.
- Routine must be absurdly small: `<15min`, one verb, one file, one definition of done. `Map ONE variable reward to product hooks` not `Map variable reward schedules`.

## Examples

- Cue: Open `🏠 Command Center` → Routine: Check `Tasks: not done sort by urgency` top 1 → Reward: Check `📈 Knowledge Graph Intelligence` for new cluster (Hunt reward)
- Anti-example: Cue: vague "work on manifesto" → Routine: undefined 3hr block → Reward: none → loop dies
