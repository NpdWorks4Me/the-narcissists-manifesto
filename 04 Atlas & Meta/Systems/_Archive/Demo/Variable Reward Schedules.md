# Variable Reward Schedules

> One idea per note. Evergreen, reusable building block.

## Definition

Intermittent, unpredictable payoffs that create stronger habit loops than fixed rewards — the core of Skinner's variable reinforcement and Nir Eyal's Hook model reward phase.

## Nuance

Not all variability is ethical. Fixed rewards build trust; variable rewards build craving. Distinguish exploitative (slot-machine) vs empowering (discovery, mastery) variability. Fixed schedules bore; highly unpredictable schedules frustrate.
